# 为AE-Style UI Resource Pack贡献

感谢你关注本资源包！我们致力于为 Minecraft 1.20 提供统一、精致的 AE 风格界面，并持续扩展对更多模组的支持。你的每一份贡献——无论是修复纹理、适配新模组，还是反馈问题——都会让这个项目变得更好。

## 📌 行为准则

请遵守开源社区的协作精神，友善沟通，尊重他人。我们期待所有贡献者共同维护一个积极、包容的环境。

## 🐛 报告问题

如果你发现界面错位、纹理显示异常或兼容性问题，请通过 Issues 提交反馈。提交时请尽量包含以下信息：

- 问题发生的模组名称及版本
- Minecraft 版本（目前仅支持 1.20.x）
- 使用的资源包版本（亮色/暗色版）
- 截图（能清晰展示 UI 异常）
- 相关日志（如有）

## 🎨 贡献方式

1. 新增模组 UI 支持
   如果你希望为某个模组添加 AE 风格界面，欢迎提交 Pull Request。
   **步骤：**
   1. 确认该模组的尚未被支持（可查看当前支持的模组列表）。
   2. 在`assets/<modid>/`下创建对应模组的资源文件。
   3. 若需要修改模组原版 GUI 的布局（如通过 OptiFine / CIT 或自定义模型），请同步调整相应的 .properties 或 .json 文件。
   4. 确保同时提供亮色版与暗色版（我们提供了快速替换像素的工具和一键处理脚本）。
2. 修复或优化现有纹理
   - 修正纹理错位、颜色偏差、模糊或拉伸问题。
   - 改进文字对比度，使其在亮色/暗色背景下都清晰可读。
   - 统一 UI 元素风格（边框、按钮、槽位等）与 Applied Energistics 2 的原版风格一致。
3. 完善文档或翻译
   - 为资源包添加语言文件（如 zh_cn.json）以支持界面文字本地化。

## 🖌️ 纹理规范

- 格式：PNG（无压缩，透明背景）
- 分辨率：尽量保持与原模组 GUI 纹理一致（常见 256×256 或 512×512）
- 风格：
  - 参考 Applied Energistics 2 的 [GUI风格](#GUI风格)：深色半透明背景、蓝色高亮边框、简洁硬朗的线条。
  - 亮色版建议使用浅灰底色 + 深色文字/边框，保持整体清爽。
- 文字：推荐使用与 AE2 相同的字体（Minecraft 默认字体或统一替换），确保在不同分辨率下可读。
- 命名：使用小写字母、下划线分隔，与模组原文件名保持一致。

## 🔧 开发环境

本资源包无需编译，你可以直接使用任意文本编辑器或图片处理软件（如 **Photoshop**、**GIMP**、**Paint.NET**）进行修改。

建议在本地 Minecraft 1.20 实例中加载资源包实时测试，确保 UI 显示正确。

## 📥 提交 Pull Request

1. Fork 仓库 并创建你的特性分支 (git checkout -b feature/amazing-ui)。
2. 提交你的修改 (git commit -m 'Add amazing UI for mod XXX')。
3. 推送到分支 (git push origin feature/amazing-ui)。
4. 在 GitHub 上打开 Pull Request，描述你的修改内容、关联的 Issue（如有），并附上对比截图（修改前后）。
5. 等待维护者审阅。若需调整，我们会与你沟通。

## ✅ PR 检查清单

在提交 PR 前，请确认：

- 纹理文件命名正确，路径与模组原结构一致。
- 亮色/暗色版本均已适配（如该模组 UI 两种版本都需要）。
- 在 Minecraft 1.20 中实际测试通过，未出现错位或显示错误。
- 没有引入其他模组 UI 的冲突或覆盖。
- 若有新增模组，已在 README.md 中更新支持列表。
